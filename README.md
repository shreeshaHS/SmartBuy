# 🛒 SmartBuy

SmartBuy is a full-stack e-commerce web application developed as a college project. It provides a simple and user-friendly platform where users can browse products, add items to their cart, place orders, and make online payments.

## ✨ Features

* User registration and login
* Product browsing and search
* Product details
* Add to cart and remove from cart
* Quantity management
* Order placement
* Online payment integration
* User order history
* Responsive user interface
* Backend API and database integration

## 🎯 Project Objective

The main objective of SmartBuy is to develop a practical e-commerce platform while gaining hands-on experience in frontend development, backend development, database management, authentication, REST APIs, and payment gateway integration.

## 🛠️ Technologies Used

* Frontend: HTML,CSS,JavaScript
* Backend: PHP
* Database: PHPMYADMIN
* Payment Gateway: Razorpay
* Version Control: Git & GitHub
